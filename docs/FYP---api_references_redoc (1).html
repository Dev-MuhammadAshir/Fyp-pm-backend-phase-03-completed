Appendix I — API Specification

Derived from SRS v2.1 §4, §7, §8, §10 and the Critical Decisions Register CA-01 – CA-24. This document is the authoritative REST contract for the implementation phase.

Authentication

Bearer JWT — 15-minute access token, Redis-backed refresh session, and JTI blacklist on logout (CA-06).

Real-Time Sync

Socket.IO over WSS with 13 domain events across project:{id} and user:{id} rooms (CA-07).

PIRAE Boundary

Advisory, rule-based engine running asynchronously via BullMQ + daily cron. It never autonomously mutates project state (CA-08).
